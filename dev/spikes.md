# Что проверить в настоящей Foundry с PF2e

Стенд (`dev/harness`) имитирует Foundry и систему pf2e, поэтому здесь — то, что подтверждает только
живой мир: Foundry v14 с pf2e 8.x и Foundry v13 с pf2e 7.x. Персонажи: один с «Поиском» в
исследовании и экспертом в Воровстве, второй — не обученный Воровству; одно чудовище.

## Броски и урон

- [ ] Спасбросок игрока кнопкой в карточке: окно модификаторов pf2e, сообщение броска в чате, итог
      и степень доходят до ведущего; «Увёртливость» меняет степень (карточка верит системе).
- [ ] «Бросить за всех» и «Модуль бросает сам»: без сообщений, итог сразу в карточке.
- [ ] Базовый спасбросок: половина при успехе и вдвое при крит. провале — так же, как кнопки урона
      системы; сообщение системы «получает N урона» с кнопкой отмены.
- [ ] Иммунитеты, слабости, сопротивления: огонь по существу со слабостью к огню, яд по нежити.
- [ ] Продолжительный урон (кислотный распылитель, отравленные дротики): состояние «продолжительный
      урон» на цели, вдвое при крите; при успехе базового спасброска — не вешается.
- [ ] Состояния со значением: «напуган 2» от безумного газа; вторая ловушка с «напуган 1» не
      понижает и не складывает.
- [ ] Атака ловушки против КБ: крит на 10 выше, Trap Finder даёт +1 к КБ против ловушек.
- [ ] Dice So Nice: карточка ждёт, пока кубики докатятся.
- [ ] Hero Point: переброс спасброска игрока — карточка пока помнит первый бросок (известное
      ограничение, проверить, как это выглядит).

## Обнаружение и обезвреживание

- [ ] Персонаж подходит к ловушке: тайная проверка Внимательности (игрок её не видит), один раз на
      ловушку; не ищущий не получает проверку у ловушки с рангом.
- [ ] Поиск выделенными: тайные броски, ответ — ведущему.
- [ ] Обезвреживание без ранга — отказ с подсказкой; с рангом — окно модификаторов, степень успеха,
      крит. провал запускает ловушку, коса требует двух успехов.
- [ ] Видимость бросков: на v13 — rollMode, на v14 — messageMode (модуль передаёт оба).

## Подписи

- [ ] Русский мир: свои подписи модуля (Рефлекс, Воровство, тошнота 1); английский мир — тоже.
- [ ] Окно области Foundry (поведение «Ловушка») открывается, все поля с подписями.
